# DSB 2.53 Trainingstimer

Offline training timer v1.4 with a German interface and saved German voice commands.

## Use

- Web: open `index.html` in a browser, or publish this folder with GitHub Pages.
- Android: download [v1.4 APK](downloads/DSB_2_53_Trainingstimer_v1_4_Android.apk).

## Features

- Full simulation: 4 × 150 seconds followed by 4 × 20 seconds.
- Separate precision and rapid training modes with a timer Reset button.
- Timer Reset keeps the entered scores.
- Record one total for 20 precision shots and one for 20 rapid shots (200 each, 400 combined).
- Manual, per-discipline automatic, and fully automatic series control.
- Adjustable loading time, attention delay, breaks and volume.
- Precision series can be ended early.
- CSV export; Android displays copyable CSV text.
- No photo recognition and no remote data service.

## GitHub Pages setup

Upload the contents of this ZIP to the repository root (the same level as this README).
In repository Settings → Pages, select Deploy from a branch → main → / (root) → Save.
The expected address for a repository named `dsb-253-training-timer` is:
https://cnyl2201.github.io/DSB-3.53-Traning-Simulator/

This address becomes usable only after GitHub Pages has been enabled and deployment succeeds.

## Android installation

The APK is self-signed. If an older installation has a different signing certificate,
uninstall it before installing this version. Android 6.0 or newer is declared by the package.
Package signatures, file integrity, and timer/scoring logic were checked; installation,
audio and display have not been tested on a physical Android phone.

## Training notes

Unofficial training aid. Follow the range officer's commands and local range rules.
Keep the app visible while timing. Scores stay in the current session; export them before
resetting the whole session or closing the app.
